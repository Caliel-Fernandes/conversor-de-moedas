# 💱 Conversor de Moedas em Java

Projeto desenvolvido em Java que realiza a conversão de moedas utilizando uma API externa de taxas de câmbio em tempo real.  
O sistema funciona via terminal, apresentando um menu interativo para o usuário escolher o tipo de conversão desejada.

---

## 📌 Funcionalidades

- Conversão de Dólar (USD) para:
  - Peso Argentino (ARS)
  - Real Brasileiro (BRL)
  - Peso Colombiano (COP)
- Conversão inversa dessas moedas para Dólar (USD)
- Consumo de API externa para obter taxas atualizadas
- Menu interativo no terminal
- Mensagem de saída detalhada com moeda de origem e destino

---

## 🛠️ Tecnologias Utilizadas

- **Java 17**
- **Gson** (para desserialização do JSON)
- **API ExchangeRate-API**
- **IntelliJ IDEA**
- **Git & GitHub**
